# Hackathon submission checklist

Status: planning checklist, not proof of eligibility or submission. Reviewed 28 September 2026. Follow linked official pages if anything changes.

## Entry and implementation

- [x] User reports joining the hackathon.
- [ ] Confirm age-of-majority and all eligibility/conflict conditions in [rules](https://amazonappdev2026.devpost.com/rules).
- [ ] Primary route: Alexa+ simulation; include functioning source and video. Optional MCP requires protocol 2025-11-25+ over Streamable HTTP.
- [ ] Select AWS Builder and document actual AWS integration.
- [ ] Build original work during the event; explain substantial updates if using a pre-existing project.
- [ ] Respect third-party licenses and rights.

## Repository and demonstration

From [overview](https://amazonappdev2026.devpost.com/) and [FAQ](https://amazonappdev2026.devpost.com/details/faqs):

- [ ] GitHub repository includes necessary source, assets, and working setup instructions.
- [ ] Public repository includes an open-source license, or private repository is shared with reviewers.
- [ ] Private route: invite `chris-trag`, `knmeiss`, `giolaq`, `anishamalde`, `mosesroth`, `emersonsklar`, and Devpost at `testing@devpost.com`; verify access and expiring invitations near submission.
- [ ] Public YouTube/Vimeo video is under three minutes and shows working functionality.
- [ ] Include product description, tool feedback, and track selections.
- [ ] Explain which AWS services actually run and how.
- [ ] Optional friction log contains only actual observations.

## Final gate

- [ ] English submission materials or required translations.
- [ ] Free reviewer access through judging, including private testing instructions if needed.
- [ ] Submit by internal target: 22 October, 8 p.m. IST.
- [ ] Official cutoff: 24 October, 12:30 a.m. IST.
- [ ] Keep submitted version stable; post-deadline submission changes require organizer allowance.
- [ ] Ravi confirms the entry is submitted, not only saved as draft.
