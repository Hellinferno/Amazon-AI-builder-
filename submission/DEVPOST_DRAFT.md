## Working title

Cashflow Assistant — a conversational cash-flow planner for small businesses.

## Inspiration

Small-business owners often need to answer a practical question quickly: will expected receipts cover an upcoming payment? The project combines accounting reasoning with conversational access to business records, so users can explore payment timing and see the assumptions behind each result.

## What it does — complete after verification

The planned experience compares a baseline cash forecast with a delayed-customer-payment scenario, explains the difference using source records, and prepares a collection reminder for review. The interface is a simulated Alexa+ experience. The backend will use Amazon Bedrock with deterministic accounting tools.
