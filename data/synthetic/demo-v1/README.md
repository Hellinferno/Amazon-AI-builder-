# Synthetic fixture: demo-v1

**Synthetic planning data, not an observed business outcome.** Names, amounts, and dates are invented. The fixture is hand-written from the golden table in [ACCOUNTING_RULES.md](../../../docs/ACCOUNTING_RULES.md); it is not generated by a script and does not depend on the current clock.

| File | Contents |
| --- | --- |
| `snapshot.json` | Business snapshot: as-of 2026-10-05, opening cash INR 50,000.00 |
| `invoices.csv` | INV-001 (Customer A, 40,000.00) and INV-002 (Customer B, 15,000.00) |
| `obligations.csv` | BILL-001 (rent, 10,000.00) and PAY-001 (payroll, 70,000.00) |
| `expected_results.json` | Test oracle for the baseline and the INV-001 14-day delay |

All amounts are unsettled and every due date equals its expected date. The payee names and categories are additions needed to satisfy the CSV contract in [DATA_MODEL.md](../../../docs/DATA_MODEL.md); the golden table does not specify them.

`expected_results.json` records the expected forecast values. The forecast engine that must reproduce them is not implemented yet.
